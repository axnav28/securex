# Submission guide

## Before sharing the repository

- Confirm the repository is public and the default branch is up to date.
- Verify the README live links and local setup commands.
- Do not commit `.env.local`, passwords, tokens, or private credentials.
- Confirm the Vercel frontend and Render API are reachable.
- Add final presentation, demo video, and approved screenshots under `submission/` and `assets/`.

## Reviewer path

1. Read the project overview in `README.md`.
2. Review the architecture in `docs/architecture.md`.
3. Open the presentation outline in `submission/PRESENTATION.md`.
4. Follow the demo sequence in `submission/DEMO.md`.
5. Run the validation commands from the README.

## Repository conventions

Application source lives in `src/`, technical documentation in `docs/`, visual material in `assets/`, and submission material in `submission/`.
